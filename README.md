
# Aeries TA Hiring Intelligence

A web-based Hiring Tracker Dashboard for Aeries Technology's Talent Acquisition team.

## Technology Stack
- Python 3.11
- Streamlit
- PostgreSQL
- Pandas
- Plotly

## Features
- Centralised hiring dashboard
- Organisation-wise hiring analytics
- Recruitment metrics and reporting
- Interactive visualisations

## Status
Initial dashboard development.
